# CS-499-Capstone.github.io
This repository showcases my CS 499 Computer Science Capstone at SNHU. It includes my original artifact, enhancements in software engineering, algorithms and data structures, and databases, along with testing documentation, narratives, instructor feedback, and revisions demonstrating my growth as a computer science professional.

## Informal Code Review Video

This video presents a code review of the original CS 330 C++ and OpenGL artifact selected for my CS 499 ePortfolio. The review is organized around the three required computer science categories:

- Software design and engineering
- Algorithms and data structures
- Databases

For each category, I describe the artifact’s existing functionality, analyze the code using relevant review criteria, and explain my planned enhancements. The analysis considers code structure, logic, efficiency, functionality, security, testing, error handling, comments, and documentation.

The video also identifies the technical skills demonstrated by each planned enhancement and explains how the work supports the five Computer Science program outcomes.

Because the video exceeds GitHub’s file-size limit, it is hosted externally.
